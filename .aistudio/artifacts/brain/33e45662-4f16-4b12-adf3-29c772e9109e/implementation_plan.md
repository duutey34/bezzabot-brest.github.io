# План запуска гостевого путеводителя «Без забот» на GitHub Pages

## Обзор
В проекте настроена автоматическая сборка через **GitHub Actions**. Это значит, что вам достаточно отправить исходный код в репозиторий на GitHub, и при каждом сохранении изменений GitHub сам соберёт проект (`npm run build`) и опубликует обновлённый сайт на бесплатном хостинге GitHub Pages.

---

## 1. Что уже подготовлено в проекте
1. **Базовый путь (`base: './'`)**: в файле `vite.config.ts` уже выставлен относительный путь. Сайт откроется корректно по любому адресу репозитория (например, `https://username.github.io/bez-zabot/`).
2. **Файл рабочего процесса (Workflow)**: создан файл `.github/workflows/deploy.yml`, который:
   - скачивает код;
   - устанавливает зависимости (`npm ci` / `npm install`);
   - собирает продакшн-версию (`npm run build`);
   - автоматически выкладывает папку `dist` в GitHub Pages.

---

## 2. Пошаговые действия для запуска

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com/) и войдите в свой аккаунт.
2. Нажмите зелёную кнопку **«New»** (Создать новый репозиторий).
3. В поле **Repository name** укажите имя, например: `bez-zabot` или `guest-guide`.
4. Оставьте репозиторий **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным).
5. Нажмите **«Create repository»**.

---

### Шаг 2. Загрузите файлы в репозиторий

#### Вариант А: Через терминал / Git (если установлен Git)
В папке с проектом выполните команды:
```bash
git init
git add .
git commit -m "Initial commit: Bez Zabot Guest Guide"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/bez-zabot.git
git push -u origin main
```

#### Вариант Б: Через сайт GitHub (drag & drop)
Если вы скачали архив проекта:
1. Распакуйте архив на компьютере.
2. На странице созданного репозитория нажмите ссылку **«uploading an existing file»**.
3. Перетащите файлы проекта (включая папку `.github` и `src`) и нажмите **«Commit changes»**.

---

### Шаг 3. Включите GitHub Pages в настройках репозитория
1. В вашем репозитории перейдите во вкладку **Settings** (Настройки) сверху.
2. В левом боковом меню выберите раздел **Pages**.
3. В блоке **Build and deployment** найдите выпадающий список **Source**:
   - Переключите с *«Deploy from a branch»* на **«GitHub Actions»**.
4. Сохранение происходит автоматически.

---

### Шаг 4. Проверка и запуск
1. Перейдите во вкладку **Actions** в верхней панели репозитория.
2. Вы увидите запущенный процесс с названием **«Deploy to GitHub Pages»**.
3. Через 1–2 минуты процесс завершится зелёной галочкой.
4. Вверху или в разделе **Settings -> Pages** появится ваша персональная ссылка на сайт вида:
   ```
   https://ВАШ_ЛОГИН.github.io/bez-zabot/
   ```

---

## 3. Резервный экспресс-вариант (без сборщика)
Если вам потребуется опубликовать сайт буквально за 1 минуту:
1. Возьмите готовый автономный файл `standalone-index.html` из корня проекта.
2. Переименуйте его в `index.html`.
3. Загрузите прямо в корень репозитория.
4. В **Settings -> Pages** выберите *Source: Deploy from a branch -> main / root* — и сайт сразу заработает без запуска npm.
